ملف تعديلات ترجمة صفحات لوحة الموظفين غير المترجمة

طريقة التركيب:
1) انسخ مجلد components فوق نفس المجلد داخل المشروع ووافق على الاستبدال.
2) احذف مجلد .next.
3) شغّل npm install ثم npm run typecheck ثم npm run dev.

يشمل:
- المستخدمون وطلبات التفعيل.
- إضافة مؤثر لحملة وتكليفات المؤثرين.
- صفحات المالية والتحويلات والقسائم والتسويات والتقارير والمشكلات.
- صفحة المشاريع التسويقية التعريفية.
- ترجمة النصوص الديناميكية الشائعة والحقول البديلة عند اختيار الإنجليزية.
- لا يغيّر بوابة المؤثر أو قاعدة البيانات، ولا يحتاج SQL.
