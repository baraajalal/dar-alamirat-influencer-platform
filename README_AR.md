# نظام العمليات المالية الكامل

## التركيب
1. انسخ محتويات هذا المجلد فوق المشروع مع المحافظة على المسارات.
2. شغّل ملف SQL التالي مرة واحدة من Supabase SQL Editor:
   `supabase/migrations/202608030023_finance_full_operations.sql`
3. أعد تشغيل المشروع.

## الفحص
```powershell
Remove-Item -Recurse -Force .next -ErrorAction SilentlyContinue
npm run typecheck
npm run lint
npm run dev
```

## الإضافات
- التحويلات المرتجعة وإعادة المحاولة دون حذف المحاولة السابقة.
- تسجيل سبب رفض البنك وربطه بتحديث البيانات البنكية.
- حفظ رابط أو مسار إثبات التحويل والمرجع البنكي.
- تتبع تجهيز وشحن وتسليم المنتجات.
- تنبيهات التأخير والتصعيد.
- تقرير أداء الفريق المالي للشهر الحالي.
- عدم احتساب التحويل الفاشل ضمن المبلغ المدفوع أو بدء الحظر.
