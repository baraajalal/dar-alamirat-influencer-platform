# Finance KPI Cards Alignment Patch

يعدّل بطاقات الإحصائيات أعلى صفحة المالية بحيث تكون جميع البطاقات متساوية بصرياً:
- مساحة ثابتة مستقلة لعنوان البطاقة.
- فاصل خفيف بين العنوان والرقم.
- الأرقام بمحاذاة موحدة في أسفل البطاقة.
- ارتفاع أدنى موحد لكل البطاقات.
- استخدام `tabular-nums` لتساوي عرض الأرقام بصرياً.

الملف المعدل:
- `app/dashboard/finance/page.tsx`

لا يحتاج SQL أو Migration.
