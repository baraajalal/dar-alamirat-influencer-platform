# تحديث التصميم فقط — دار الأميرات

هذا التحديث بصري فقط ولا يغيّر قاعدة البيانات أو APIs أو منطق الحفظ والبحث.

## الملفات الموجودة

- `app/page.tsx`
- `app/globals.css`

## طريقة التركيب

1. خذي نسخة احتياطية من الملفين الحاليين.
2. انسخي مجلد `app` إلى جذر المشروع.
3. وافقي على استبدال `app/page.tsx` و`app/globals.css` فقط.
4. شغّلي:

```cmd
npm run typecheck
npm run dev
```
