# Popup Brand Color Patch

هذا التعديل يغيّر ألوان الـ popup الخاصة برسائل النجاح والخطأ لتصبح بنفس درجات هوية دار الأميرات المعتمدة بدلاً من الأخضر/الأحمر الافتراضي.

## الملفات المعدلة
- `components/feedback-modal.tsx`

## النتيجة
- خلفية الـ popup أصبحت متوافقة مع الهوية البنفسجية.
- دائرة الأيقونة أصبحت بدرجات الهوية.
- عنوان الرسالة والنصوص الفرعية أصبحت من نفس السلم اللوني.
- زر الإغلاق أصبح بنفس الـ brand gradient المعتمد في النظام.
