# Ten-day MVP scope

## Included

- Secure authentication and role-based access.
- Influencer profile and social accounts.
- Campaign management and influencer assignment.
- Content submission, review, revision, approval, and archive.
- Payment record creation and status tracking.
- Employee ownership, timestamps, workload, and performance measurements.
- Post URL registration and historical metric snapshots.
- Manual metric entry fallback when a platform API cannot return data.
- Audit log and basic operational reports.

## Future modules supported by the architecture

- Tasks and project management.
- Events and activities.
- Vendors, budgets, and procurement.
- Advanced BI dashboards and automated notifications.

## Explicitly deferred from the ten-day delivery

- A complete Trello/SmartSuite replacement.
- Mobile applications.
- AI-based influencer recommendations.
- Full automation for every social network without official API permissions.
- Complex accounting or ERP integrations.
